# Air Canvas

Air Canvas is a virtual drawing application built using Python, OpenCV, and MediaPipe.

## Features
- Draw using hand gestures
- Erase drawings
- Save drawings
- Multiple drawing tools

## Technologies Used
- Python
- OpenCV
- MediaPipe

## How to Run

1. Install required packages:

```bash
pip install -r requirements.txt
```

2. Run the project:

```bash
python air_canvas.py
```
