# Air Canvas UI Icons Upgrade

This branch focuses on improving the user experience and visual appearance of the Air Canvas project.

## ✨ Features Added

- Professional toolbar icons
- Modern top navigation layout
- Improved button alignment
- Better visual feedback for active tools
- Cleaner and more organized interface
- Enhanced usability while drawing

## 🛠 Tools

- Draw Tool
- Eraser Tool
- Color Picker
- Brush Size Control
- Shape Tool
- Save Canvas
- 3D Export
- Zoom Controls

## 🎯 Goal

Transform the Air Canvas from a basic drawing application into a polished and professional-looking gesture-controlled drawing platform.

## 🚀 Future Improvements

- Dark/Light Theme Toggle
- Animated Toolbar
- Custom Icon Pack
- AI Shape Recognition
- PDF Export
- Advanced Brush Effects

## 🖥 Tech Stack

- Python 3.11
- OpenCV
- MediaPipe
- NumPy

## 📂 Branch Purpose

This branch is dedicated to UI/UX enhancements and experimentation.

The stable version remains available in the `main` branch.

## 📸 Preview

Gesture-controlled drawing with a modern professional toolbar and icon-based controls.
